# Models

`rnnoise-bd.rnnn` is the "beguiling-drafter" RNNoise model from
[GregorR/rnnoise-models](https://github.com/GregorR/rnnoise-models), trained for voice over recording noise.
ffmpeg's `arnndn` filter uses it for the "Stronger" noise reduction setting. The model repository states that
its model files are not subject to copyright. Replace the file (or set `RNNOISE_MODEL`) to try another model.
